# Sample pages from AllJobs

Upload your saved pages into this folder (GitHub web UI: **Add file → Upload files**, on the
branch `claude/pensive-rubin-x5glzv`). The scraper is built against these, so the more
representative they are, the fewer fixes it needs later.

Save each page in Chrome with **Ctrl+S → "Webpage, HTML only"** (or "Complete" - either works;
only the `.html` file is needed, not the `_files` folder).

| File name | What to save |
|---|---|
| `search-1.html` | A results page after you've searched with some filters (region / category) |
| `search-2.html` | Page 2 of that same search (so I can see how pagination works) |
| `job-1.html` | A job page **while logged in**, showing the apply / send-resume button |
| `job-2.html` | A job page where the ad includes a phone number (if you can find one) |
| `job-3.html` | Any other job page (different category) |
| `urls.txt` | The browser address of each saved page, one per line, with its file name |

Privacy: pages saved while logged in can contain your name, email or phone. Open the files in
Notepad and search for those before uploading, or tell me and I'll strip them.
